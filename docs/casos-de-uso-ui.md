# Casos de uso de pantalla (UI)

> Casos verificables de cada pantalla, con ID estable (`UI-<pantalla><nn>`). Se prueban en el
> Browser pane a **375 px** (celular) en modo claro y oscuro. Lo que depende del teléfono real
> (instalar, login de Google) se marca **manual** y lo prueba el usuario.
>
> Al agregar o cambiar una pantalla, se suma o actualiza su caso en el mismo commit. "Última
> corrida" dice la fecha y el resultado, o "sin correr". **(auto)** = cubierto además por
> `src/App.test.tsx` y corre en cada `npm test`.
